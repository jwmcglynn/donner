# Security Policy

## Supported Versions

Donner v0.8 is the only version supported with security updates. Historical versions are not
supported before v1.0.

| Version | Supported          |
| ------- | ------------------ |
| v0.8.x  | :white_check_mark: |
| v0.5.x  | :x:                |
| v0.1.x  | :x:                |

## Reporting a Vulnerability

File an issue or use private vulnerability reporting.

Level 3 status of Values and Units: Level 3 is the more mature level (Candidate Recommendation Draft) and is the level SVG 2 references. It already defines calc(), the em, ex, ch, rem, vw, vh, vmin, vmax and absolute units, angles, time, frequency and resolution, url(), strings, custom-ident and position. Level 4 (Working Draft) adds the root-relative and font-metric units (rex, cap, rcap, rch, ic, ric, lh, rlh), vi and vb, the small, large and dynamic viewport units, ratio, dashed-ident, src(), and every math function other than calc(). Rows for Level 4 additions say so in their notes or are grouped under the Level 4 functions. attr() and toggle() are in neither level's Technical Report (the Level 4 change log defers them to Level 5).

Out of scope for a script-less SVG user agent, and why: CSSOM and WebIDL sections of every spec (no script engine or object model binding); the SVG DOM interface sections 4.3 to 4.7 of the types chapter (same reason); Values 4 section 3 (combination procedures, which belong to animation); Values 4 URL processing model (fetch integration); time and frequency units (no consumer in a static renderer). Each still has a `not-applicable` row.

# Coordinate systems, transforms and units

Part of the [W3C specification audit](../design_docs/0071-w3c_spec_audit.md). One row per element,
attribute, property, value and feature in scope. Findings come from reading Donner source at
revision `b39a524a2` and the specification versions listed below. No code was built or executed
for this ledger, so every behavioral claim is a code-reading result until a test confirms it. All
paths are relative to the repository root.


Scope: SVG 2 chapter 8 (Coordinate Systems, Transformations and Units) in full, CSS Transforms Module Level 1 and Level 2, and Geometry Interfaces Level 1 where Donner has a C++ equivalent. All Donner behavior statements are by code reading of the Donner source; nothing was executed. Layout (viewports, transforms, units, bounding boxes) is computed once in the ECS under `donner/svg/components/` and consumed by both the CPU renderer and the GPU renderer, so unless a row says otherwise a rule holds, or fails, identically in both.

## Inventory

Derivation. SVG 2 chapter 8: one `feat:svg2/coords-...` row per normative rule, walking sections 8.1 to 8.14 in order (each step of the equivalent-transform algorithm in 8.2, each branch of the intrinsic ratio algorithm in 8.12, each unit of CSS Values Level 3 for 8.9, each step of the bounding box algorithm in 8.10, each row of the table in 8.11 as a cross-reference), plus `prop:`/`val:` rows for `vector-effect` (8.13) and `val:` rows for every `preserveAspectRatio` keyword. CSS Transforms Level 1: the property index (`transform`, `transform-origin`, `transform-box`) with a `val:` row per keyword and per function, every grammar production of section 7.2, and one `feat:css-transforms-1/...` row per rule in sections 2 to 14. CSS Transforms Level 2: the property index (`translate`, `rotate`, `scale`, `transform-style`, `perspective`, `perspective-origin`, `backface-visibility`), every 3D function of section 12.2, and the rules of sections 3, 6, 11, 15, 17. Geometry Interfaces: only members with a C++ counterpart in `donner/base/Transform.h`, `Box.h`, `Vector2.h`.

Out of scope for a user agent without script, each still given a `not-applicable` row: the SVG DOM interfaces of coords 8.14, section 7.5 of css-transforms-1, CSSOM serialization, the CSS box model consequences of transforms (stacking contexts, containing blocks, overflow), 3D rendering (Level 2 section 3 lets a 2D-only user agent reject it), and the IDL-only parts of Geometry Interfaces. The viewBox, preserveAspectRatio, transform, gradientTransform and patternTransform attribute-index rows themselves belong to the element ledgers; this ledger covers their grammar and semantics as features. Value rows for properties that are not implemented at all are folded into the property row.

# Document structure and global attributes

Part of the [W3C specification audit](../design_docs/0071-w3c_spec_audit.md). One row per element,
attribute, property, value and feature in scope. Findings come from reading Donner source at
revision `b39a524a2` and the specification versions listed below. No code was built or executed
for this ledger, so every behavioral claim is a code-reading result until a test confirms it. All
paths are relative to the repository root.


Scope: SVG 2 CR chapters struct (5), embedded (12.4, `foreignObject` only), linking (16, the `a` and
`view` elements, URL reference processing, fragment identifiers), conform (2.2, 2.3 processing
modes, 2.4.6 error processing), render 3.2 (rendered versus non-rendered elements), interact 15.9
(the `script` element) and styling 6.2 to 6.5 (the `style` element, `class` and `style`
attributes). Geometry properties (`x`, `y`, `width`, `height`), presentation attributes and CSS
properties are audited in other ledgers and are only referenced here.

All Donner paths are checkout-relative. No code was built or executed: every behavior statement is
a code-reading result ("by code reading") unless a named test asserts it. A row is `conformant`
only when the implementing code was read and a named test asserts the behavior;
`conformant-untested` means the code was read and no test was found.

  one rendering case each (nested `svg` with a 2:1 viewBox in a square viewport and the mirrored
  ratio).
- `attr:transform@svg` (struct.html#SVGElement): nested `svg x="10" y="10" width="50" height="50"
  viewBox="0 0 100 100" transform="translate(20 0)"`; expect the viewport itself shifted by 20.
  Same on the root `svg`.
- `feat:svg2/svg-outermost-x-y-ignored`: root `svg x="50" y="50"`; expect content at the origin.
- `val:requiredExtensions/empty-string` (struct.html#RequiredExtensionsAttribute): `rect
  requiredExtensions=""`; expect not rendered (the current unit test asserts the opposite).
- `feat:svg2/switch-eligible-children`: `switch` with a literal `foreignObject` first child (with
  and without `requiredExtensions`) and a shape fallback; record the intended result.
- `feat:svg2/switch-does-not-affect-style-script`: a `style` element inside a `switch` after a
  matching child, and a `style systemLanguage="xx"`; expect both sheets to apply.
- `feat:svg2/conditional-in-never-rendered-container`: `clipPath` with two rects, one carrying
  `systemLanguage="xx"`; expect only the other to clip.
- `feat:svg2/conditional-animation-elements`: `animate systemLanguage="xx"`; expect no animation.
- `attr:media@style`: `style media="print"` with a rule that would change fill; expect no effect
  when rendering to a screen target.
- `attr:title@style`: two `style` elements with different `title` values; expect only the first
  title's set to apply.
- `feat:svg2/style-child-element-error`: `style` containing a child element followed by CSS text;
  expect the document to load with a warning.
- `feat:svg2/xml-stylesheet-processing-instruction`: a document with `<?xml-stylesheet
  type="text/css" href="x.css"?>` before the root; expect it to load (sheet loading optional).
- `feat:svg2/a-nested-links`: `a` inside `a`; expect both subtrees rendered.
- `feat:svg2/foreignobject-content-not-rendered`: `foreignObject` containing a `rect` and an
  XHTML `div`; expect nothing rendered and siblings unaffected.
- `feat:svg2/view-element-not-rendered`: a `view` element with a `viewBox` among shapes; expect
  no effect on rendering.
- `feat:svg2/url-same-document-detection`: a document loaded with a known URL whose `use` refers
  to that same URL plus a fragment; expect same-document behavior once a document URL exists.

# Animation (SVG 2 Appendix D, SVG Animations Level 2, SMIL Animation)

Part of the [W3C specification audit](../design_docs/0071-w3c_spec_audit.md). One row per element,
attribute, property, value and feature in scope. Findings come from reading Donner source at
revision `b39a524a2` and the specification versions listed below. No code was built or executed
for this ledger, so every behavioral claim is a code-reading result until a test confirms it. All
paths are relative to the repository root.

## Specs read

| Spec | Level | Maturity | Dated URL read |
| --- | --- | --- | --- |
| SVG 2, Appendix D: Animating SVG Documents | 2 | W3C Candidate Recommendation Snapshot, 06 October 2026 | https://www.w3.org/TR/2026/CR-SVG2-20261006/animate.html |
| SVG Animations | Level 2 | Editor's Draft, 10 November 2026. No published TR exists; this is the draft the CR element and attribute indexes link to, so every row anchored to it carries draft status | https://w3c.github.io/svgwg/specs/animations/ |
| SMIL Animation | 1 | W3C Recommendation, 04 September 2001 | https://www.w3.org/TR/2001/REC-smil-animation-20010904/ |

Caveat: SVG Animations Level 2 is an unpublished draft that still contains editorial notes (for example "Attribute syntax needs fixing" on begin, dur, end, min, max and repeatDur). Where it defers to SMIL Animation, the SMIL Recommendation text was used. The CR chapters conform.html (processing modes), struct.html (use element animations) and styling.html (presentation attributes) are cited by anchor only; their own rows belong to other ledgers (`structure.md`, `styling_properties.md`) and their text was not re-read here.

Out of scope for a script-free SVG user agent: the IDL chapter of the draft (TimeEvent, SVGAnimationElement, SVGSVGElement time control), the event attributes onbegin, onend and onrepeat, hyperlink activation of animations, and the ARIA section. Each still has a row, classed not-applicable, with the C++ counterpart named where one exists.

## Tests to create

- `attr:dur` (https://w3c.github.io/svgwg/specs/animations/#DurAttribute): `<animate attributeName="width" from="0" to="100" dur="0s"/>` and `dur="-1s"` should hold 0 for an indefinite simple duration.
- `attr:end` / `feat:svg-animations/interval-computation` (https://www.w3.org/TR/2001/REC-smil-animation-20010904/#Timing-EvaluationOfBeginEndTimeLists): `begin="5s" end="2s" dur="4s"` should never become active.
- `feat:svg-animations/sandwich-priority-order` (https://www.w3.org/TR/2001/REC-smil-animation-20010904/#AnimationSandwichModel): `<set id="b" begin="a.begin" .../>` placed before `<set id="a" begin="1s" .../>` on the same attribute; b should win.
- `feat:svg-animations/conditional-processing` (https://w3c.github.io/svgwg/specs/animations/#ConditionalProcessing): `<animate systemLanguage="zz" .../>` should never apply.
- `val:href/mpath-shape-element` (https://w3c.github.io/svgwg/specs/animations/#MPathElementHrefAttribute): `<mpath href="#c"/>` where c is a circle; the target should travel the circle's equivalent path.
- `val:values/motion-coordinate-pairs` (https://w3c.github.io/svgwg/specs/animations/#AnimateMotionElement): `<animateMotion values="10mm,20mm;30mm,20mm" dur="2s"/>`.
- `val:to/to-overrides-by` (https://www.w3.org/TR/2001/REC-smil-animation-20010904/#AnimFuncValues): `<animateTransform type="translate" to="100" by="10" dur="2s"/>` should behave as a to-animation.
- `val:to/discrete-to-animation` (https://w3c.github.io/svgwg/specs/animations/#ValueAttributes): `<animate attributeName="width" to="100" calcMode="discrete" dur="2s"/>` sampled at 0.5s (base value) and 1.5s (100), and again with keyTimes="0;0.25".
- `attr:keySplines` (https://w3c.github.io/svgwg/specs/animations/#KeySplinesAttribute): `values="0;1;2" calcMode="spline" keySplines="0 0; 1 1 0 0 1 1"` should be rejected; a malformed keySplines with calcMode="linear" should be ignored.
- `attr:values` (https://w3c.github.io/svgwg/specs/animations/#ValuesAttribute): `values="0;;100"` should be an invalid list, `values="0;100;"` should be two values.
- `val:type/rotate` (https://w3c.github.io/svgwg/specs/animations/#AnimateTransformElementTypeAttribute): `from="0 50" to="90 50"` (two numbers) should be invalid.
- `val:attributeName/prefixed-name` (https://w3c.github.io/svgwg/specs/animations/#AttributeNameAttribute): `<set xmlns:x="http://www.w3.org/1999/xlink" attributeName="x:href" to="#b"/>` on a use element.
- `val:attributeName/css-property` (https://w3c.github.io/svgwg/specs/animations/#AttributeNameAttribute): `<set attributeName="mix-blend-mode" to="multiply"/>` and `<animate attributeName="class" .../>`.
- `feat:svg-animations/animateMotion-target-elements` (https://w3c.github.io/svgwg/specs/animations/#AnimationAttributesAndProperties): animateMotion on a tspan or stop should have no effect.
- `val:begin/repeat-value` (https://w3c.github.io/svgwg/specs/animations/#RepeatValueSyntax): a bare `begin="repeat(2)"` form.
- `val:begin/event-value` and `feat:svg-animations/timing-events` (https://w3c.github.io/svgwg/specs/animations/#EventValueSyntax): `begin="a.endEvent"` should start when a ends without host dispatch.
- `val:dur/media`, `val:min/media`, `val:max/media`, `val:repeatCount/indefinite`, `val:repeatDur/indefinite`, `attr:origin`: simple parser-level cases; no test was found by name.
- `feat:svg-animations/paced-distance` (https://w3c.github.io/svgwg/specs/animations/#complexDistances): paced color values and paced rotate values with differing centers.
- `attr:keyTimes` (https://w3c.github.io/svgwg/specs/animations/#KeyTimesAttribute): invalid keyTimes with an indefinite simple duration should be ignored, not disable the animation.
- `attr:href` (https://w3c.github.io/svgwg/specs/animations/#HrefAttribute): `href="foo"` (no fragment) should affect no target even when an element with id foo exists.

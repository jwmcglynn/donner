## Inventory

Derivation:

- Elements and attributes: the clipPath and mask lines of the SVG 2 CR element and attribute indexes (clipPath, mask; clipPathUnits, maskUnits, maskContentUnits, x, y, width, height on mask), with one `val:` row per enumerated value.
- Properties: all 20 entries of the CSS Masking property index (clip, clip-path, clip-rule, mask, mask-border and its six longhands, mask-clip, mask-composite, mask-image, mask-mode, mask-origin, mask-position, mask-repeat, mask-size, mask-type), each with `val:` rows for every keyword, function and grammar alternative. For clip-path the `<basic-shape>` functions are the eight listed in CSS Shapes 1 section 3.1 (inset, xywh, rect, circle, ellipse, polygon, path, shape) and the box keywords are `<geometry-box>` = `<shape-box>` | fill-box | stroke-box | view-box. Value lists that CSS Masking imports by reference (`<repeat-style>`, `<bg-size>`, `<position>`) were read from CSS Backgrounds 3.
- Features: one row per normative prose rule of CSS Masking sections 2, 5, 6, 7.10, 9, 10 and Appendix B and C, plus the clipping, masking, stacking-context and overflow rules of SVG 2 render.html (3.2, 3.4.1, 3.9, 3.11), coords.html (8.2 viewports, 8.10 bounding boxes, 8.11 object bounding box units) and the UA style sheet rule in styling.html 6.8.
- Out of scope for an SVG user agent without script or CSS box layout, each with a `not-applicable` row: the WebIDL interfaces (Appendix C), CSS animation types, CORS fetch and timing rules for cross-origin sources (section 10; only same-document references resolve), and the `clipped` bounding-box option. `mask-border-*` and the positioned-mask longhands are in scope as properties (they apply to SVG elements) and are recorded as missing. Box-model-only wording (border-radius corner shaping for box clips, box-decoration-break, visible scrolling mechanisms) has no SVG counterpart and has no row.

# SVG 2 test coverage audit: resvg-test-suite versus the SVG 2 CR

Part of the [W3C specification audit](../design_docs/0071-w3c_spec_audit.md). Findings come from
reading Donner source at revision `9a134c3eb` and the specification versions listed below. No code was
built or executed for this ledger, so every behavioral claim is a code-reading result until a test
confirms it.

Scope: which SVG 2 features (CR Snapshot 2026-10-06) the vendored upstream resvg corpus does not
exercise, which resvg cases Donner skips or relaxes, what Donner's extension corpus and unit/renderer
tests already cover, and which new Donner SVG suite cases are needed. This is a test-coverage audit,
not an implementation audit; implementation remarks are limited to what was needed to classify a
row and are marked "unverified" unless the consuming code was read.

Checkout revision: `9a134c3eb` (main). All paths are checkout-relative. The resvg corpus is
`third_party/resvg-test-suite/tests/` (1,679 SVG files in 7 chapter directories and 107 feature
directories). The Donner extension corpus is `donner/svg/renderer/tests/donner_svg2_corpus/tests/`
(22 SVG/PNG pairs: geometry 11, painting 4, shapes 5, structure 1, plus READMEs). Donner native
animation/interaction scenarios live in `donner/editor/tests/svg_suite_animation/` (driven by
`donner/editor/tests/SvgSuiteAnimation_tests.cc`).

CR base URL used below: `https://www.w3.org/TR/2026/CR-SVG2-20261006/` (abbreviated `CR/` in the
matrix; every `CR/x.html#y` expands to that base plus `x.html#y`).

## Summary

- The resvg corpus contains zero animation, interaction, linking-navigation or focus cases
  (no `<animate>`, `<set>`, `<animateMotion>`, `<animateTransform>`, `pointer-events`, `tabindex`,
  `:target`, `<view>` or `svgView` anywhere). Everything in those areas depends on Donner's own
  native scenarios, which today cover timing, interpolation, motion, contextual `use`, hover and
  click.
- The largest static SVG 2 gaps with no resvg case at all: `vector-effect`, `pathLength`
  on any element and the new `path-length` property, `inline-size` wrapping,
  `white-space` and `text-overflow`, `d` and `cx/cy/r/width/height` as CSS properties, `transform-box`, `symbol` `x/y/width/height/refX/refY`, marker
  `refX/refY` keywords, `lang` without namespace, `foreignObject`, image
  `object-fit/object-position`, SVG view fragments and media fragments on image references, and clip-path `inset()/ellipse()/polygon()/path()`.
- Several of those gaps have Donner unit or renderer-golden coverage but no portable suite case:
  `vector-effect` (`RendererRegression_tests.cc` golden), `pathLength` (`RendererGeodeGolden_tests.cc`
  `stroking_pathlength`), `inline-size` (`text_inline_size_wrap` golden), `white-space`
  (`TextSystem_tests.cc`), basic-shape clip paths (`InsetClipPath_tests.cc`,
  `PolygonClipPath_tests.cc`, `PathClipPath_tests.cc`), `fr` (`radial-fr-1/2` goldens). Promoting
  these to SVG/PNG pairs with independently reasoned references is the cheapest coverage win.
- Where resvg does cover an SVG 2 feature, Donner usually runs it, but several SVG 2 rows rest on
  skipped or render-only cases: radialGradient `fr=0.7` (skipped, reference disagreement) and
  `fr=0.5`/`fr=-1` (render-only UB), textPath `method=stretch` (skipped), `with-invalid-path-and-xlink-href`
  (skipped), `mixed-children-2` (skipped), clip-path `circle()` with `stroke-box`/`view-box`
  (skipped, harness background mismatch), `structure/use/xlink-to-an-external-file` (skipped),
  7 filter-function cases (skipped; count re-read at `b39a524a2`), `text/font-size-adjust`,
  `text/direction/rtl`,
  `text/unicode-bidi/bidi-override`, `text/glyph-orientation-vertical` (skipped).
- Reference conflicts with the CR: `painting/stroke-linejoin/miter-clip.svg` encodes the
  `miter-clip` join that the CR removed (Issue 1065, March 2026) and Donner currently passes it by
  implementing `miter-clip`; the two `non-presentational-attribute.svg` cases encode SVG 1.1
  (geometry in `style` ignored); `rgb-int-int-int.svg` uses the resvg UB marker for valid CSS Color
  4 syntax; `fr=0.7` paints a reversed gradient where the CR requires transparent output (RC1 to RC4, RC6).
- The Donner extension corpus is still a seed (22 pairs) concentrated on geometry `auto`/CSS
  lengths and a few painting defaults; its READMEs and SVG `<desc>` links cite the svgwg.org
  Editor's Draft, not the CR anchors. New cases should cite CR anchors.
- resvg categories that test SVG 1.1 features the CR removed (`tref`, `kerning`,
  `glyph-orientation-horizontal`, `enable-background`/`BackgroundImage`, `clip` property,
  `icc-color`, `dominant-baseline: reset-size/use-script`, `requiredFeatures`) are correctly
  render-only or ignored in Donner and need no new cases.

Counts (148 matrix rows): covered 53 (of which 6 are covered only by the Donner extension corpus or
Donner native scenarios), resvg-only-skipped 10, needs-new-suite-case 71 (several of which have
Donner unit or renderer-golden coverage but no portable SVG/PNG pair; see column 6),
removed-from-CR 14.

## SVG2 feature coverage matrix

Column notes. "resvg coverage": count of resvg SVG files that use the feature in a way that asserts
the SVG 2 behavior, with up to three example paths relative to `third_party/resvg-test-suite/tests/`.
"Donner run status": from the registrations in `donner/svg/renderer/tests/resvg_test_suite.cc`
(not from a test run): `default` = compared at default budget; `thresholded` = relaxed
threshold or pixel budget; `golden-override` = Donner-specific reference; `v049-ref` = refreshed
300x300 resvg v0.49.0 reference; `skipped` = `Params::Skip`; `render-only` =
`UndefinedBehavior` or `DeprecatedInSVG2` (renders, no comparison). Donner coverage paths are
relative to the checkout.

CR anchor (not the Editor's Draft).

## Reference conflicts

Upstream fixtures stay unchanged; each item needs a Donner case or a recorded policy with cited
rationale.

- RC1 `painting/stroke-linejoin/miter-clip.svg`: the reference image shows the clipped miter
  extension (green past the black miter-limited join). The CR lists only `miter | round | bevel`
  for `stroke-linejoin` (CR/painting.html#LineJoin) and changes.html#painting records that
  `miter-clip` and `arcs` were removed in March 2026 (Issue #1065). Under the CR the declaration is
  invalid, the join is `miter`, and the green path is fully covered. Donner registers this case at
  the default budget and implements `MiterClip` (`donner/svg/renderer/Renderer.cc:286`,
  `donner/svg/renderer/RendererTinySkia.cc:329`), so the suite currently rewards the removed value.
  `arcs.svg` is already render-only. Needs `painting/stroke-linejoin/miter-clip-invalid.svg` and a
  decision on whether to keep `miter-clip` as an extension (SVG Strokes draft).
- RC2 `structure/style-attribute/non-presentational-attribute.svg` and
  `structure/style/non-presentational-attribute.svg`: references show nothing rendered because
  the files carry `version="1.1"` and expect SVG 1.1 to ignore `height` in `style`. The CR removed
  `version` and makes `height` a CSS property (CR/geometry.html#Sizing), so the rect must render.
  Donner runs both render-only (`DeprecatedInSVG2`). Needs TC22 cases.
- RC3 `painting/fill/rgb-int-int-int.svg`: the reference is the resvg UB marker for space-separated
  `rgb()` syntax. The CR references CSS Color (CR/changes.html#color); the space-separated form is
  CSS Color 4 while the styling chapter lists css-color-3 for `color`. Donner runs it render-only.
  spec-ambiguity: which CSS Color level governs SVG 2 paint parsing; a Donner case should pin the
  chosen level.
- RC4 `paint-servers/radialGradient/fr=0.7.svg` (skipped) and `fr=0.5.svg` (UB marker): the CR
  says coincident circles paint nothing, and Donner's skip records that a start circle containing
  the end circle should be transparent while the reference paints a reversed gradient
  (CR/pservers.html#RadialGradientElementFRAttribute). The CR excerpt read for this audit states
  the cone and coincident-circle rules but not the `fr > r` case explicitly (see Unverified).
- RC5 Text bounding box for paint servers: `painting/stroke/radial-gradient-on-text.svg` (skipped)
  and `linear-gradient-on-text.svg` (thresholded) use glyph ink extents; Donner uses glyph cells.
  CR/coords.html#BoundingBoxes defines the box algorithm; the exact text-box wording was not in the
  portion of coords.html read (unverified).
- RC6 Reference backgrounds: several skips and thresholds (`circle-shorthand-with-*-box`,
  `use/xlink-to-an-external-file`, textPath 0.89 thresholds, `text-anchor/coordinates-list`) cite a
  background mismatch between a reference and Donner's transparent canvas.
  CR/render.html#ParentCompositing composites a top-level standalone document onto an opaque white
  backdrop and preserves opacity in every other case.
  The color ledger records the facts: both renderers return a transparent canvas, and the pixel
  comparison uses straight-alpha output against transparent-background references with no
  flattening, so no test can detect a white backdrop either way
  (`feat:svg2-render/standalone-document-white-backdrop` and
  `feat:svg2-render/test-harness-backdrop` in [color_compositing.md](color_compositing.md)). The
  missing backdrop is rated low for the library API and is an unmet requirement for standalone
  output. Whether flattening in the harness would let these cases compare was not established.
- RC7 `text/textPath/mixed-children-2.svg` (skipped): SVG 2 continues text after a `textPath` from
  the path end point; the reference continues from the occupied text extent. Donner cites

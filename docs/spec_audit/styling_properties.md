# SVG 2 styling chapter and the CSS properties it requires

Part of the [W3C specification audit](../design_docs/0071-w3c_spec_audit.md). One row per element,
attribute, property, value and feature in scope. Findings come from reading Donner source at
revision `b39a524a2` and the specification versions listed below. No code was built or executed
for this ledger, so every behavioral claim is a code-reading result until a test confirms it. All
paths are relative to the repository root.


Scope: SVG 2 chapter 6 (Styling) in full; the cross-check of the presentation attribute table and the required property list against the Donner property registry; full property and value rows for display, visibility, opacity, overflow (with overflow-x and overflow-y), color, isolation, mix-blend-mode and will-change; and the cascade rules the chapter relies on. Properties owned by other ledgers appear only as registration cross-check rows. All Donner behavior statements are by code reading of the pinned checkout; nothing was executed.

## Registry cross-check summary

(a) Required properties with no registry entry and no consumer: `text-align`, `text-align-last`, `vertical-align`, `font-feature-settings`, `font-variant-ligatures`, `font-variant-caps`, `font-variant-numeric`, `font-variant-east-asian`, `font-variant-position`, `font-variant-alternates`, `transform-box`, `path-length` (new in this CR), plus three whose name is whitelisted but never parsed or read: `shape-rendering`, `text-rendering`, `text-overflow`. From the latest CSS Overflow TR: `overflow-x`, `overflow-y`. Referenced by the CR outside 6.7: `will-change`.

(b) Registered properties the CR list does not name: `font-synthesis-small-caps`, `font-synthesis-style`, `overflow-wrap`, `word-wrap`, `text-transform`, `text-decoration-thickness`, `mix-blend-mode`. All are permitted extensions.

(c) Presentation attribute names contrary to the CR: accepted but not in the table: `color-rendering`, `glyph-orientation-horizontal` (name only, no effect), `inline-size`, `text-orientation` (take effect). Accepted on the wrong elements: `transform` on `pattern`, `linearGradient` and `radialGradient`; every presentation attribute on foreign-namespace elements. Accepted on too few elements: `flood-opacity` and `stop-opacity` (only on their consuming elements), `x`, `y`, `width`, `height` on `symbol` (direct setter) and `foreignObject` (absent). Correctly rejected: `font`, `isolation`, `mix-blend-mode`, `text-indent`, `font-kerning` and the other attribute-less properties; `fill` on animation elements; `x`/`y` on text content elements; `r` on `radialGradient`; `gradientTransform` and `patternTransform` on other elements.

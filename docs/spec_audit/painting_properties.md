# SVG 2 painting properties (painting chapter and CR property index)

Part of the [W3C specification audit](../design_docs/0071-w3c_spec_audit.md). One row per element,
attribute, property, value and feature in scope. Findings come from reading Donner source at
revision `b39a524a2` and the specification versions listed below. No code was built or executed
for this ledger, so every behavioral claim is a code-reading result until a test confirms it. All
paths are relative to the repository root.


Scope: every property of the SVG 2 CR property index except the geometry properties (cx, cy, r, rx, ry, x, y) and text-anchor, with every value of each, plus the algorithms and prose rules of the painting chapter and the presentation attribute syntax rules that govern these properties. Findings come from reading Donner source at revision `b39a524a2`; nothing was built or run, so every behavioral statement is a code-reading result. Where the CPU renderer (tiny-skia) and the GPU renderer (Geode) differ, the row says so; otherwise the statement holds for both.
